# 上板与测量运行

## 系统连接

PMT 输出连接采集板模拟输入，板卡经千兆以太网连接计算机，通过 JTAG 配置与调试。整机采用 12 V 直流输入，板上完成模拟和数字电源转换。当前测量接口为板上通道 1，对应 AD9694 D 通道。散热采用铝制散热器和主动风冷。

## 整机实物

- photos/enclosure.png：整机外观。
- photos/platform.png：测量平台。
- photos/board.png、photos/cooling.png：板卡及散热安装。

本次测量对应实现运行为 `impl_raw_recording_20261103`。当前模型标识为 0x20261103，原始帧为 1281 点，CNN 输入为 257 点、10 ns/点。

## 配套上位机

在配套 MATLAB 上位机目录运行 `SiTCP_AI_V14`。默认 FPGA 地址为 192.168.10.16，TCP 端口为 24，RBCP UDP 端口为 4660。计算机网口配置在相应网段。

界面提供原始波形、能谱、AI 状态、AI 通过波形与能谱四页。配对快照读取同一事件的 257 点输入与得分。

## 参数应用

按“暂停并应用全部配置”完成暂停排空、模式设置、初始化、处理参数更新，最后设置上传点数。原始波形设为 1281 点，CNN 默认得分阈值为 Q14 整数 4043，即 0.24676513671875。数字触发阈值与 CNN 得分阈值分别配置。

点击 START 后采集。波形和能谱显示按钮仅切换页签，数据接收和保存连续运行。

## 数据保存与计数率

设置样品来源、批次和保存目录，启动保存后启动采集。完整事件按数量及时间条件写入分段 MAT，并保存 JSON 元数据；停止保存时写入剩余数据。

TIME48 在事件触发处锁存，每刻度 4 ns。平均事件率为 `(N-1)*250000000/(末时间戳-首时间戳)`，近期率使用最近最多 128 个事件。START 开始新的统计区间。

## 测量流程

记录样品、PMT 高压、数字阈值和处理模式，应用配置并采集。在相同测量条件下完成本底与标准样品测量，保存波形、能谱和运行参数，计算净计数率、效率及探测限，并与固件身份一起归档。
