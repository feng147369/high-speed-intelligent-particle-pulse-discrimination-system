# 仿真与功能验证

本目录收录当前二分类模型版本的验证结果及日志，结果按真实 CNN、顶层事务与上位机协议组织。

## 验证项目

- 命令、配置顺序和默认阈值。
- 50/500/15 预筛边界与双样点相位。
- 1281 点原始取窗、257 点预处理及窗口边缘。
- CNN 整数参考、C 仿真和 C/RTL 联合仿真。
- 原始满码否决、事件关联及波形和能谱写入。
- 暂停排空、TCP 背压和完整包输出。
- 时间戳、事件率、分段保存及四页上位机。

## CNN 数值与满码检查

当前模型使用 128 条真实波形完成 C 仿真和 C/RTL 联合仿真，与整数参考逐分数一致。24 帧实际 CNN RTL 测试包含 16 组合成边界帧和 8 条真实留出波形，覆盖预触发、末点、单点满码、五种抽取相位、额外样点处理、得分与否决组合、版本和复位状态。

## 真实顶层

传统模式的两个预筛通过事件正常上传。AI 测试检查预筛窗外单点满码对最终上传和能谱写入的影响，并在 TCP 背压下检查 2577 字节完整包。

## 上位机

协议测试覆盖 TCP 分包粘包、32 位能谱、RBCP 分段快照、有符号得分、模型和满码状态、分段保存、事件率及四页显示。

## 结果入口

| 文件 | 内容 |
|---|---|
| results/default_threshold_sim.json | 默认阈值和配置验证 |
| results/veto_simulation.json | 原始满码及实际 CNN RTL 验证 |
| results/host_results.json | 上位机验证 |
| logs/ | CNN 与上位机测试日志 |

综合、实现和验证汇总见 `../build/reports/verification_results.json`。
