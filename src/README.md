# 设计源码与接口

## 公开模块与目录

整机顶层名称为 `top_tcp_adc`。本目录收录自主数据处理模块、CNN、IP 配置、约束及权重复制脚本，文件清单见 `source_manifest.json`。

| 目录 | 内容 |
|---|---|
| rtl/core/ | ADC、时钟配置、JESD204B 接口、基线、特征、能谱和调度 |
| ai/rtl/ | 事件门控、AI 接口及氚水预筛 |
| ai/rtl/cnn/ | 定点 CNN RTL 与 ROM 初始化文件 |
| ip/ | 时钟、JESD204B、FIFO、RAM 和 ILA 配置 |
| constraints/ | 引脚与时序约束 |
| ai/scripts/ | 综合前权重复制脚本 |

## 数据通道

AD9694 以 500 MSPS 采样，FPGA 在 250 MHz 时钟域内每周期处理两个连续样点。板上通道 1 对应 ADC D 通道，接收 Lane 2，从 `rx_tdata[95:64]` 提取样点，完成字节对齐和数据格式转换。

## 事件处理

首次样点达到“动态基线＋数字触发阈值”时建立事件，锁存基线和事件号。预筛跳过前 50 点（100 ns），观察至第 500 点（1 μs），后 450 点累计至少 15 点过阈（30 ns）。原始缓存为 1281 点，首尾跨度 2.56 μs，包含 120 点预触发数据。预筛通过后死区为 20 μs，恢复时间为 320 ns。

传统模式按预筛放行；AI 模式要求预筛通过、CNN 得分通过及原始帧满码检查通过。

## CNN 输入和判决

1281 点原始波形在中心位置 0、5、10、……、1280 进行相邻五点整数均值处理，形成间隔 10 ns 的 257 点输入，边缘采用端点延拓。最前 16 点用于估计输入基线。

网络由三层一维卷积、ReLU、两次池化、全局平均和全连接组成。输出为有符号 Q14：显示得分＝整数值/16384。默认阈值为 4043，即 0.24676513671875，得分严格大于阈值时通过。

完整原始帧任一点达到 65532 或以上时，AI 支路执行满码否决，结果同时参与上传和能谱累积。模型标识为 `0x20261103`。

## 配置命令

固定 9 字节格式：`A5 5A CMD P1 P2 P3 P4 C3 3C`，多字节字段高字节在前。

| CMD | 功能 |
|---|---|
| 11 / 12 / FA | 启动、暂停、复位 |
| 22 | 数字触发阈值 |
| 23 | 原始波形上传点数 |
| 24 | 输出谱道数 |
| 27 / 28 | 总积分门长、尾总积分比较参数 |
| 33 | 兼容输出配置 |
| 34 | 传统或 AI 模式 |
| 35 | 有符号 Q14 得分阈值 |

应用顺序：暂停排空、设置模式、等待初始化、设置处理参数、最后设置上传点数、启动采集。

## 数据包

带时间戳波形：`5A A5 0D LEN16 N16 TIME48 [N个uint16原始样点] 0A A0`。总长为 2N＋15，1281 点为 2577 字节。TIME48 在触发时锁存，250 MHz、4 ns/刻度。

能谱：`5A A5 0C LEN16 BINS16 TYPE [每道uint32计数] 0A A0`。总长为 4BINS＋10，8192 道为 32778 字节。TYPE 90、91 对应 PSD 两个谱桶。多字节字段均为大端。
