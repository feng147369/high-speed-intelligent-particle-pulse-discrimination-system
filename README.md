# 基于 FPGA 与轻量神经网络的高速氚水在线测量系统

全国大学生嵌入式芯片与系统设计竞赛 2026 · FPGA 自主选题赛道 · 高级组

## 项目简介

本项目面向核设施及环境水体中氚的在线监测需求，研制了一套集高速采集、实时波形处理、轻量神经网络甄别和网络测量分析于一体的氚水在线测量系统。

系统采用 CaF₂(Eu) 晶体探测器和光电倍增管完成信号探测与光电转换，使用 AD9694 四通道 14 位 500 MSPS ADC、LMK04828 时钟器件和 XC7K325T FPGA 构成高速数字化电子学。FPGA 通过 JESD204B 接收数据，以 250 MHz 双样点并行流水结构完成动态基线估计、触发、峰值、总积分、尾积分、脉宽和过阈样点统计。

系统部署定点轻量一维 CNN，通过统一事件号和事件缓存，将预筛、特征提取与 CNN 结果关联到同一事件。传统模式按预筛结果放行，AI 模式联合预筛、CNN 得分和原始波形满码检查形成最终判决。

有效事件进入原始波形上传和能谱累积路径，经 SiTCP 千兆以太网传输至 MATLAB 上位机，实现参数配置、波形与能谱显示、AI 状态回读、原始数据保存和氚水测量分析。系统已完成硬件设计、FPGA 开发、上位机集成、上板运行及氚水实测。

## 主要功能

- 500 MSPS 原始采样与 JESD204B 接收，每周期处理两个连续样点。
- 动态基线、候选触发、过阈样点预筛和波形特征提取。
- 1281 点原始事件缓存，首尾跨度 2.56 μs。
- 五点均值与降采样形成 257 点 CNN 输入。
- 定点 CNN 推理、Q14 得分判决和原始满码否决。
- 同一事件的预筛、特征、波形与 AI 判决关联。
- 波形及累计能谱完整包调度、48 位 FPGA 事件时间戳。
- 暂停排空、配置边界控制及网络背压处理。
