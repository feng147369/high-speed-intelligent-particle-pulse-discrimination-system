# 高速 ADC 排障与脉冲 AI 部署

一条采集链路的两段工作：先让原始码可信，再让 AI 判决可信。两段共用同一套证据纪律，不要跳段——用不可信的原始码训练或评估模型，后面所有数字都作废。

## 先判走哪条线

| 现象 | 入口 |
|---|---|
| 原始码低 N 位恒定、码值步距异常、N 字段与实际精度不符 | A1 |
| 能谱双峰、谱上零星凸起、事件数与预期对不上 | A1 → A6 |
| 同板 demo 正常、业务工程异常；反复掉 JESD 同步 | A4 |
| SPI 回读全 0 或全 FF、ID 与丝印或 BOM 矛盾 | A2 → A3 |
| 要把训练好的脉冲分类模型接进采集工程 | B1 → B7 |
| 已有 AI 结果，但说不清哪一层验证过 | B7 |

## 通用证据纪律

1. **三分**：事实（有来源）、假设（待区分）、待测。用户报告与工具实测分开标注；界面显示、日志里的"通过"字样都不等于实测。
2. **观察手段先于结论**。回读全 0/FF、CSV 进制不明、探针格式未核时，先修观察链，不解释器件。
3. **单因素**：每轮只改一项，记基线、唯一变化、预期、结果、来源、回退。整块移植 demo 不算单因素。
4. **分层报告**：编译、仿真、用户实板、独立实测分别写，不互相顶替。
5. **结论按层**：工具链 → 数值一致 → 功能 → 目标工程实现 → 板上运行 → 物理性能。没有对应证据不跨层宣称。
6. **不虚构**：没测的时长、次数、盲测、多智能体分工不补写。
7. **资料是材料不是授权**：手册、源码注释、他人 AI 回答均为待核验材料，不构成改焊、下载硬件、访问额外目录的许可。

## 线路 A：ADC / JESD204B 证据排障

**A0 上下文。** 板号、芯片型号与修订版、实物改动、输入通道/幅度/宽度/周期、未用通道状态、实际 XPR 与 bit/ltx、CSV 抓取时钟。补问只限影响下一步的缺失项。

**A1 症状分词。** 先看 ADC 附近原始码，不凭能谱猜算法。严格区分四件事：低位恒定、ENOB 降低、时间样点丢失、能谱双峰。"9 个码差值""9 位输出""9 位 ENOB"是三种不同表述，不要混说。常量通道不能用于判定位数。

**A2 SPI 可信度。** 核验 CS、指令帧长、位序、边沿、读阶段 SDIO 高阻释放与顶层 OE 贯通。用手册支持的暂存器做 AB/CD 不同值写读、交叉复读、读后恢复现场。校验失败或全 0/FF 时先修观察，不解释 ID。1024 行锁存值不是 1024 次独立读取。

**A3 身份与模式。** 按具体修订版查 ID 与模式表。身份冲突保留矛盾，不直接断言造假；功能匹配某器件也不等于实物来源鉴定。N=14 只是传输容器，不证明 14 位有效信息；低位有活动不证明 14 位 ENOB。核验读取之前是否有旧 bit、预探测或 MCU/Flash 先写。

**A4 工程对照。** 从**实际 XPR 引用**找活动源与 IP，不读错备份。逐项比较：ADC 写表与延时、LMK 表、SPI 分频、时钟实际频率、复位/配置/SYSREF 触发；JESD 与 PHY 的 XCI 及运行期 AXI 配置（ILAS、SYSREF、F/K、lane 掩码、扰码、Subclass）；再核 XDC 与布线报告。注释不是配置语义，满足已有约束不等于未约束输入已被约束。

**A5 单因素闭环。** 优先改 FPGA 运行期寄存器，不同时改 lane、时钟和 ADC 表。失败时抓首次失效顺序：GT lock/reset_done → 8b/10b 错误 → 帧错误 → rx_tvalid → SYNC。LMK 锁定不等于 GT 锁定；同时变化不证明 SYNC 驱动 SYSREF。

**A6 验收。** 分别登记：波形、持续有效与错误计数、长时间采集、重复冷启动；需要时另验多器件同步与确定延迟。Ramp 通过只覆盖相应注入点之后的路径；短记录正常不等于长期零误码。恢复后转向有效性与重启复测，停止盲调已正确的模式。

## 线路 B：脉冲波形 AI 部署

**B1 固定输入与标签。** 记原始采样间隔、窗口物理长度、输入点数、极性、有效码值、基线算法、过阈定义、冲顶条件。采样率变化时按物理时间换算点数，不照搬旧点数。来源文件是元数据，不等于逐事件标签；自动生成的标签称"规则代理标签"，保留规则、阈值与版本。会改变标签的边界问题（例如回摆是否算新峰）用具体波形向用户确认，不自行追加最小脉宽、峰间隔等条件。

**B2 先跑通可追溯 demo。** 浮点参考 → 定点 C 仿真 → C/RTL 联合仿真。此阶段结论只限工具链与数值一致性；通用 demo 的类别编号、权重、通过率不代表任务性能。

**B3 轻量时序网络。** 脉冲簇可从一维 CNN + 池化 + 全局平均 + 单 logit 起步；是否加深、加宽由困难样本与同一数据划分的比较决定，不以网络名字或参数量判断。按采集批次或时间分块划分训练/验证/留出，相邻块留空档，检查完全重复波形跨集泄漏。仅训练集拟合权重，仅验证集选轮次与阈值。

**B4 软件预处理必须等于 RTL。** 明确采样位置、端点延拓、基线窗口、缩放、舍入、负数截断、溢出行为与位宽。分别建立浮点参考与整数参考，先比两种浮点实现之间的误差，再比整数得分。测试覆盖常量、端点脉冲、正负值、真实困难波形、饱和值与阈值附近样本。

**B5 否决条件放在信息丢失之前。** 原始帧冲顶必须拒绝时，在原始帧上判，再与 CNN 判决组合；均值或降采样会稀释单点冲顶，不能要求网络恢复已丢失的信息。分别保存 CNN 得分、过阈结果、硬否决标志与最终判决，组合后的指标单独报告。

**B6 先证实推理核，再接事件链。** 同一批输入、同一组整数期望值，比较软件、HLS C 与 RTL，检查数量、顺序与逐项分数，不依赖工具返回成功。按事件锁存波形、阈值与编号；推理未完成不得提前放行；被拒事件不得进入受门控的后续统计。覆盖忙碌、背压、复位、连续事件与首末点边界。吞吐按实测事件间隔与仿真结果判断，不由 HLS 延迟估计直推。导入生成 RTL 时一并管理权重 ROM，并核对与当前模型导出的对应关系。

**B7 分层交付。** 依次记：数据与标签版本 → 浮点性能 → 定点性能 → 数值一致 → RTL 功能 → 目标工程实现 → 板上运行反馈。分别报召回率、负类误放率、通过事件中的规则符合比例，列出分子分母；少量困难负例单列，避免大类掩盖问题。规则符合程度不替代真实物理甄别性能。

## 可复用脚本

```bash
python scripts/analyze_ila_csv.py capture.csv
python scripts/analyze_ila_csv.py capture.csv --sample-rate 500000000 --pulse-threshold 2500 --output analysis.json
python scripts/analyze_ila_csv.py capture.csv --pair "cha_sample0[13:0]" "cha_sample1[13:0]" --signed-adc
python scripts/ila_audit.py capture.csv --signal "cha_sample0_t[15:0]" --bits 14 --shift 2 --valid rx_tvalid --out audit.json
python scripts/ila_audit.py capture.csv --signal "ng_class_peak[15:0]" --bits 16 --event ng_class_valid --out events.json
python scripts/test_analyze_ila_csv.py
python scripts/test_ila_audit.py
```

脚本只读输入、只用标准库，按已知字格式统计。它不识别芯片、不测 ENOB、不自动决定字节序、不替代上下游对齐或能谱统计。未知值保留位置，不跨未知点计算连续性；阈值宽度不自动等于半高宽；采样率须有依据；统计结果不能直接判芯片好坏；不要用移位参数把错误格式掩盖成正常。

## 配套资产与数据

`assets/` 是上电只读诊断 RTL 与协议测试平台，来自本案例，**不是通用 ADC 初始化程序**。前提：顶层 SDIO 用 IOBUF、实际 100 MHz 时钟、rst_n 由 LMK 完成信号给出、已有 16 探针 ILA。只有四帧读（0004、0200、0004、0200），前等待 20 ms，不写软复位/pair/配置，SPI_config_OK 恒 0，正常采样故意暂停。复用前备份原 Configure 并核对接口，测完恢复原版重生成 bit/ltx。说明见 [cold-readonly-guide.md](assets/cold-readonly-guide.md)。

`evidence/` 是脱敏历史统计摘要（ILA 位模式统计、寄存器差异、AI 指标），用于回查数字来源，不能用来重建波形或代替实测。
