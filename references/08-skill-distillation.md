# 技能包的提炼过程

本文件对应三项内容：**从哪些失败或观察中总结**（第二节、第三节的"失败或观察"列）、**如何验证有效**（同表"如何验证有效"列 + 第五节 + [06-verification.md](06-verification.md)）、**边界如何确定**（同表"边界如何确定"列 + 第六节）。

提炼的目标不是把某次成功的寄存器值或某组权重打成补丁，而是把**改变过判断的证据**固化成下次仍会生效的工作关卡。下面每一行都对应一次真实的失败、误判或观察，而不是先写规则再倒推案例。

## 一、提炼方法

1. 只收"改变过结论"的经验。没改变判断的操作细节（软件菜单、编译顺序）不入包。
2. 每条规则必须能答三问：**从哪个失败或观察来**、**用什么证据证明它有效**、**它的边界在哪**。
3. 边界和规则同等重要。写入"不能证明什么"，防止下次把局部证据当全局结论。
4. 案例参数与通用规则分开存放，避免把某次配置当成默认答案。

## 二、线路 A（ADC / JESD204B）：从失败或观察到规则

| 失败或观察 | 提炼的规则 | 如何验证有效 | 边界如何确定 |
|---|---|---|---|
| SPI 回读全 0/FF，顶层读阶段 SDIO 仍被驱动 | 先证明观察可靠，再解释器件 | 争用负例复现 + 修正后暂存器 A5/5A 交叉复读通过 | 不把所有 FF 归因于 OE；其他工程可能另有原因 |
| 标称 AD9694 却读到 ID=DC，按 08 配置后改善 | 身份与模式交叉核验，保留矛盾 | 官方手册 ID 表 + 可靠回读 + 用户模式试验 | 不直接断言假芯片；08 不是通用修复 |
| 同一板 demo 正常、业务工程失稳 | 从实际 XPR 对照运行期配置 | IP 与 LMK 表一致，单改 data3（0x010 bit0）后用户确认恢复 | 不把"该位设 0"当作所有系统的默认答案 |
| 短波形健康但 SYSREF 仍跳 | 运行数据与同步要求分开验收 | CSV 统计 + 用户约 15 分钟观察 | 不证明长期零误码与重启延迟一致 |
| 元件被误称"串联电容"，实为 240 Ω 到地 | 实物拓扑优先于图纸与旧记录 | 本地更正记录 + TI 负载条款 | 未见原始连线证据时不改写拓扑，不推断可换 0 Ω |
| 移植 demo 报 module not found、源码非 UTF-8 | 集成前核对接口、依赖、XPR 登记与编码 | 实际报错 + 已通过的编译 | 不整块覆盖业务工程 |
| "9 位"口头描述含糊 | 先把症状转成位集合与码值间隔 | 旧数据间隔 32、新数据间隔 1 | 不据此计算 ENOB |
| 改 13 条未公开寄存器后仍全 0 | 每项干预对应一个可证伪假设，记录无效结果 | 保留原始初始化差异并对照 | 不把"无效"当作"全部寄存器无关" |
| 同地址在不同型号上功能不同 | 以确切型号与修订版比较模式与格式 | 官方 14+2 零 / 9+7 零，与切片推导吻合 | 不泛化到所有 ADI ADC |
| 只改 0200 低位恢复 | 最小变量实验优于同时改时钟、算法、lane | 用户改动报告 + 独立 CSV 统计 | 未固定输入的其他轮次不冒充严格 A/B |
| 回读模块可能自证 | 增加原始位序与采样相位观察 | 协议仿真 DB/DC、冷读 DC/07、DB/00、DC/08 通过 | 仿真器不鉴定实物、不证明板级波形 |
| 冷读易被旧 demo 污染 | 写入前纯只读，确认物理掉电与启动源 | 仿真确保只有四帧读、无软复位/索引写入 | 冷上电的实板执行仍由用户保证 |
| 改善后仍有稀有小凸起 | 先确认触发窗口确实覆盖目标能区 | 旧捕获区间与新道号映射对照 | 映射变化须重新推导阈值 |

## 三、线路 B（脉冲 AI）：从失败或观察到规则

| 失败或观察 | 提炼的规则 | 如何验证有效 | 边界如何确定 |
|---|---|---|---|
| 最初 demo 来源不可追溯、无人维护 | 优先选来源可追溯、能拿到模型与转换脚本的 demo，先独立跑通 | hls4ml 官方模型 128 组输入完成 C/RTL 数值对照，独立内核实现通过 | 官方来源提高可追溯性，不等于适合脉冲分类 |
| 汇总特征与短感受野网络对困难波形仍混淆 | 用同一数据划分比较保留时序信息的小 CNN | 比较多种小网络后选 5/9/15 卷积核长感受野结构，再做独立前向核验 | 不规定所有任务必须用三层或这组核长 |
| 257 点在 2 ns 间隔下只覆盖 0.512 μs | 先固定物理时间，再确定点数与预处理 | 1281 点 / 2 ns → 257 点 / 10 ns 逐点对照 | 换采样率须重新推导，不能只改时间轴或重复点 |
| 示例模型跑通后仍不代表任务效果 | demo 只复用结构与工具链，权重由任务数据验证或训练 | 25755 条新实测波形训练，保留时间留出集 | 不能把 demo 的一致率当任务准确率 |
| "多少峰""回摆算不算"会改变标签 | 把人工语言变成可执行规则，用边界实例向用户确认 | 用户确认"超过设定阈值"和"再次过阈就算"，据此生成标签 | 未引入额外峰间隔、脉宽限制；规则不等于物理真值 |
| 来源文件内部同时含候选与干扰波形 | 文件来源只作元数据，逐事件生成标签 | 本底中符合规则的事件同样列为候选，保留各来源统计 | 不为提高指标把整个本底批次强行标负 |
| 提高阈值可降低误放但也会大量漏判 | 验证集选工作点，同时报召回、误放与分组表现 | 留出正类 977/1161 通过，同时列出未饱和少峰负例 10/66 误放 | 不只报总体指标或挑最好看的数字 |
| 浮点正确不保证截断、端点与定点正确 | 为整数计算建立独立参考，再逐级核对 | 两个整数参考探针得分精确一致，128 组 HLS C/RTL 分数匹配 | 采样公式、位宽、阈值变化后需对应版本验证 |
| 五点均值可能隐藏单点冲顶 | 必须拒绝的原始条件在降采样前检测 | 饱和负例 CNN 误放由 80 条降为 0，24 帧 RTL 边界测试通过 | 满码数值来自本案例有效码格式，不可硬套其他格式 |
| 单核推理正确不等于事件在线处理正确 | 输入、阈值、结果按事件关联，测试背压与复位 | 事件级仿真中两候选仅一事件通过，拒绝事件未进入后续统计 | 有限测试不证明任意事件率与无限突发下无丢失 |
| 工具生成结果含权重 ROM 等独立资产 | RTL、ROM 与模型版本一并核对 | 导出 ROM 与综合读取记录一致，目标工程实现通过 | 生成成功不能代替目标工具对实际资产的验证 |

## 四、为什么切分成这些文件

| 文件 | 保存什么 | 判断依据 |
|---|---|---|
| `SKILL.md` | 实际执行时会改变决策的步骤与约定 | 读一遍即可开工，不依赖其他文件 |
| `references/01-evidence-gates.md` | 关卡、流程图、每关的判据 | 排障必须按顺序过闸，跳关会误判 |
| `references/02-device-rules.md` | 型号指纹、寄存器位语义、拓扑禁忌 | 用错一次就烧板或误判器件 |
| `references/03-case-evidence.md` | 本案例事实链与官方定义对照 | 让另一位使用者不必猜数字来源 |
| `references/04-experiment-contracts.md` | 回读、冷上电、模式修复、残余谱的契约 | 决定实验能不能算数 |
| `references/05-ai-case-parameters.md` | 预处理公式、网络、定点格式、指标 | 参数可复现，但明确标注是案例值 |
| `references/06-verification.md` | 验证层次、行为验收场景、未完成证明 | 判断"这个技能本身是否可信" |
| `references/07-collaboration-and-workflow.md` | 提示词、动作、纠错轨迹、工作流设计 | 说明规则从哪来，便于报告引用 |
| `evidence/` | 脱敏统计摘要 | 回查数字，不用于重建波形 |

## 五、技能有效性的判定

有效性证据是已经发生的多层验证，不是自我声明：

- 工具链层：通用 demo 128 组输入、640 个输出，浮点与定点索引一致，RTL 与 C 逐项一致。
- 数据层：25755 条新实测波形完成训练与时间留出评估。
- 数值层：浮点两实现最大绝对误差 4.48×10⁻⁶；独立整数参考探针精确一致；3864 条留出判决一致率 99.77%。
- 硬件层：新权重 128 组 HLS C 与 RTL 整数得分与参考精确匹配。
- 系统层：事件级门控仿真确认拒绝事件不进入后续统计；目标工程综合、实现与时序通过；用户实测反馈整链跑通。
- 脚本层：四个脚本的标准库回归全部通过（明细见 [06-verification.md](06-verification.md)）。

## 六、适用边界

- 本包适用于已有脉冲波形采集、需要把轻量模型逐级部署到 FPGA 的任务，以及采用 AD9694/AD6684、LMK04828、XC7K325T 一类器件的采集链排障。
- 不提供通用粒子真值，不保证任意增益、噪声、触发阈值或采样率变化后的性能。
- 案例只有两批实测数据，采用同批时间留出，缺少独立新批次的物理真值评估；标签来源是用户波形规则，输出称为候选判决。
- 组合模型仍漏 184 个规则正例，对 66 个未饱和少峰负例误放 10 个，这些是后续采集与训练必须保留的边界。
- 器件侧未完成物理真伪鉴定、SYSREF 随机跳变的电气根源定位、规定时长的独立误码与重复上电确定延迟测试；低位有活动不构成 ENOB 测量。
- 本包是从两个已完成案例归纳的技能，未在其他全新项目中做过独立迁移实验。

## 七、形成路径

两条线都经历了同样的收敛过程：**未收敛的经验猜测 → 基于数据与手册的分层检查 → 可复现的实验契约与脚本 → 保留验收边界**。没有把某次"改好了"的写法直接包装成通用一键修复，也没有把"跑通了"升级为未测得的性能承诺。
